## Future Locale Addition (Evidence)

Adding a locale requires only catalog data + registration; the core lookup/fallback algorithm is not touched. This is proven by `tests/i18n/test_localization_foundation.py::ExtensionTests` (synthetic `th-TH` and `ja-JP` locales loaded without any core change) and documented in `docs/localization.md`:

```python
from nyron_i18n import MessageCatalog, with_builtin_catalogs

svc = with_builtin_catalogs(default_locale="en-US")
svc.register(MessageCatalog(locale="th-TH", messages={
    "common.ok": "ตกลง",
    "common.cancel": "ยกเลิก",
}))
svc.get("common.ok", "th-TH")  # "ตกลง"
```

Catalogs may also be loaded via `MessageCatalog.from_dict(...)` or `MessageCatalog.from_json(...)`.
