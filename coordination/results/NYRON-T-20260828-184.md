## RuntimeContext Authority Construction

`AttemptExecutor.execute()` now keeps PURE Modules on the existing `runtime_context=None` path. For an effect-capable Module, it maps the immutable ModuleDefinition effect declaration to the frozen effect vocabulary, asks Capability Authority for current, time-valid grants whose registered CapabilityType is compatible with every required effect class, and binds those grants to the exact current AttemptAuthority tuple. The bounded context is built only after the Attempt is durably ACTIVE and from canonical activation/accounting evidence.

The Module receives immutable `CapabilityHandle` values, optional opaque `ResourceHandle` values, identity metadata, and the bounded broker. It does not receive StateStore, SQLite connections, raw CapabilityGrant or ResourceLease authority objects, credential values, `ResolvedCredentialHandle`, sockets, HTTP/Provider clients, sessions, or OS/network objects. Missing authority or unsupported effect classes fail before host invocation; dispatch revalidates exact Attempt and CapabilityGrant truth inside Effect Authority's transaction.
