## Finding F-001 — Required Fix

The reviewed implementation hard-coded:

```text
TRIGGER / REQUIRED_NEXT => SINGLE_SOURCE
REQUIRED_LATEST / OPTIONAL_LATEST => MULTI_SOURCE
```

Task 172 proved this contradicts frozen Graph authority, which treats `activation_mode` and `connection_policy` as independent input-port contract fields and explicitly permits `MULTI_SOURCE TRIGGER`.

Required:

- represent an input port's frozen `connection_policy` independently from `activation_mode`;
- Graph cardinality validation MUST read/use that independent policy, never infer it from activation mode;
- `MULTI_SOURCE TRIGGER` must be representable and publish successfully when all other Graph rules pass;
- `SINGLE_SOURCE` must fail closed on more than one incoming edge;
- preserve existing activation semantics; do not reinterpret `TRIGGER`, `REQUIRED_NEXT`, `REQUIRED_LATEST`, or `OPTIONAL_LATEST`;
- preserve deterministic immutable/replay Graph publication.

Use the smallest representation compatible with existing Module/Graph ownership. If adding the frozen-required field reveals a genuinely unfrozen serialization/default/migration semantic, STOP with exact Architecture Finding instead of guessing.

Do not amend frozen design documents.

## Finding F-002 — Required Fix

Task 172 reproduced that a pre-171 SQLite database has `graph_edges` without `role`, and post-171 `GraphRepository.publish()` then fails with:

```text
sqlite3.OperationalError: table graph_edges has no column named role
```

Required:

- add the narrow existing-project migration idiom in `_create_schema()` using `PRAGMA table_info(graph_edges)`;
- if `role` is missing, execute a bounded additive `ALTER TABLE graph_edges ADD COLUMN role TEXT NOT NULL DEFAULT 'NORMAL'` or the exact SQLite-safe equivalent preserving current frozen role semantics;
- reopening an accepted pre-171 database must preserve old rows and permit a new edge-bearing GraphRevision publication;
- fresh database creation must remain correct;
- restart/reopen must be idempotent.

Do not introduce a generic migration framework.
