### ResourceHandle

```text

```

### RuntimeContext

```text

run_ref: str
attempt_seq: int
fencing_token: str
```

3. `metadata` must contain only exact key/value string pairs; no arbitrary live object may cross there.
4. `effect_broker` must be `None` or the exact supported `BoundedWriteEffectBroker` type; raw `EffectAuthority` or another object must be rejected.
